# High-Level Architecture

- **SPA**: Preact + Vite, minimal shell, auth flows.
- **MPA**: Fresh, server-rendered pages.
- **Worker**: Deno process, asynchronous jobs when added.
- **API**: Deno + Hono, REST + WS ready (no domain).
- **DB**: Postgres, auth core only.
- **KV**: Valkey for cache/session helpers.

## Security

- HTTPS everywhere.
- Authn/Authz at middleware + handler.
- Server validates all inputs.
