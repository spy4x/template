# Key Templates for GitHub Issues

This document outlines the key templates for creating GitHub Issues. Each template includes the title, labels, description, and checklist to ensure consistency and facilitate feedback into the system. System-required issues are flagged to ensure the system recognizes them. Comments are included to allow users to directly reply and answer questions.

## Template 1: Define the Tech Stack
- **Title**: Define the Tech Stack
  - Keywords: Tech Stack, Configuration, AI Recommendation
  - **System Required**: Yes
- **Labels**: Configuration, Tech Stack
- **Description**:
  - Objective: Determine the technologies that will be used to build the application. This includes selecting tools and frameworks for the frontend, backend, database, and other essential components.
  - Questions to Answer:
    1. What technologies will be used for the frontend (if applicable)? <!-- Reply with your answer -->
    2. What technologies will be used for the backend? <!-- Reply with your answer -->
    3. What type of database will be used? <!-- Reply with your answer -->
    4. What additional tools are required? <!-- Reply with your answer -->
    5. Should the AI recommend or choose the tech stack? If yes, provide any constraints or preferences. <!-- Reply with your answer -->
    6. Is a tech stack required for this project? If not, explain why and describe the alternative approach. <!-- Reply with your answer -->
  - Deliverables:
    - A detailed list of technologies and tools to be used.
    - Justifications for each choice.
    - Any constraints or limitations to consider.
    - If AI is allowed to choose, a summary of the AI’s recommendations.
    - If no tech stack is required, a clear explanation and alternative approach.
- **Checklist**:
  - [ ] Frontend technologies selected (if applicable).
  - [ ] Backend technologies selected (if applicable).
  - [ ] Database type chosen (if applicable).
  - [ ] Additional tools identified.
  - [ ] AI recommendation requested (if applicable).
  - [ ] Explanation provided if no tech stack is required.
